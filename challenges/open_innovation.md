# Challenge 3 — 💡 Open Innovation

**Difficulty:** Self-selected · **Stack:** Any suitable open-source AI toolkit or licensed open-weight model

## Mission

Build a small, original application where the AI component is central rather than decorative. You may start from your own code or an existing responsibly licensed library or model.

## Suitable example directions

- A revision assistant that generates quiz feedback using a small open-weight model **with factuality warnings**.
- A local document finder using embeddings and citations to relevant passages.
- An accessible interface for classifying images or text with an open-source model.
- An experimental notebook comparing small models on a reproducible fictional-data task.
- A model evaluation harness that exposes weaknesses on clearly defined examples.

You may use model hubs or hosted services only if their licenses, availability, costs and privacy restrictions permit them. **Never embed tokens in a public repository.**

## Minimum acceptance criteria

- Explain the problem and the real contribution your team made.
- Identify the open-source AI framework/model, version and license.
- Provide reproducible code and a demonstrable result; show baseline vs. improvement where sensible.
- Add a README, appropriate open-source license, and meaningful limitations.
- Do not use undisclosed private datasets or misrepresent model outputs.

**Organizer note:** Official prize-category eligibility must be checked against the current MLH rules. Using a package called 'AI' does not itself establish eligibility.

## Demo (60–90 seconds)

Problem → working demo → how AI works → original work → limitation → public team repository.
